## [1.0.0] - 2024-02-27

### Added
- Initial release of JDCloud CLI
- Support for VM (Virtual Machines) with full CRUD operations
- Support for VPC (Virtual Private Cloud) with VPC and subnet management
- Support for OSS (Object Storage Service) with bucket and object management
- Dual mode support: Real API mode and Mock mode
- Multiple authentication methods (AK, STS, role-based)
- Multi-region support
- Multiple output formats (JSON, YAML, table)
- Command auto-completion
- Configuration file management
- Polling and waiting functionality
- Batch operations
- Template-based deployment
- Scriptable execution
- Result filtering and querying
- Comprehensive documentation
- Installation scripts
- Makefile for building and testing
- Unit tests for core functionality
