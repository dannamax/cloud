# CMDB 平台架构文档

## 1. 项目概述

### 1.1 项目简介
CMDB（Configuration Management Database）配置管理数据库平台，用于管理企业服务器资产、监控运维状态、追踪变更历史。

### 1.2 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端框架 | React | 18.2.0 |
| 构建工具 | Vite | 5.1.0 |
| UI 框架 | Tailwind CSS | 3.4.1 |
| 状态管理 | Zustand | 4.5.0 |
| 路由 | React Router DOM | 6.22.0 |
| 图表 | Recharts | 2.12.0 |
| 表格 | TanStack Table | 8.21.3 |
| 后端框架 | Express | 4.18.2 |
| 数据库 | better-sqlite3 | 11.9.1 |
| 文件处理 | Multer | 1.4.5 |
| Excel 导出 | xlsx | 0.18.5 |

### 4.2 模块详细说明

#### 4.2.1 仪表盘 (Dashboard)
- 服务器总数/在线/离线统计
- 按环境/角色/机柜分布
- 角色类型可视化
- 变更趋势图表

#### 4.2.2 服务器管理 (Servers)
- 服务器列表展示（支持排序、筛选、分页）
- 环境筛选（全部环境 + 单个环境）
- 角色类型筛选
- 服务器详情查看
- 新增/编辑/删除服务器
- Excel 导入导出
- 自定义列配置

#### 4.2.3 机柜管理 (Cabinets)
- 机柜列表
- 机柜详情（位置分布）
- 机柜容量统计

#### 4.2.4 变更历史 (History)
- 服务器变更记录追踪
- 变更类型：状态变更、属性修改、上下架
- 操作人员记录

#### 4.2.5 审计日志 (Audit)
- 用户操作审计
- 按操作类型/用户/时间筛选
- 操作详情记录

#### 4.2.6 成本统计 (Cost)
- 服务器成本汇总
- 按环境/角色类型分组
- 成本趋势图表

#### 4.2.7 系统设置 (Settings)
- 系统参数配置
- 数据导入导出
- 数据清空

```
                       │ key          │
                       │ value        │
                       └──────────────┘
```

### 5.2 核心表结构

#### servers - 服务器表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| name | TEXT | 服务器名称 |
| environment | TEXT | 环境 |
| system_ip | TEXT | 系统 IP |
| manage_ip | TEXT | 管理 IP |
| oob_ip | TEXT | BMC IP |
| cabinet | TEXT | 机柜 |
| u_position | INTEGER | U 位 |
| role | TEXT | 角色 |
| role_type | TEXT | 角色类型 |
| sn | TEXT | 序列号 |
| brand | TEXT | 品牌 |
| model | TEXT | 型号 |
| status | TEXT | 状态 |
| online_status | TEXT | 在线状态 |
| ... | ... | 其他属性 |

#### change_logs - 变更日志表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| server_id | INTEGER | 服务器 ID |
| change_type | TEXT | 变更类型 |
| before_status | TEXT | 变更前 |
| after_status | TEXT | 变更后 |
| operator | TEXT | 操作人 |
| created_at | TEXT | 创建时间 |

#### audit_logs - 审计日志表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| user_id | INTEGER | 用户 ID |
| action | TEXT | 操作类型 |
| target | TEXT | 操作对象 |
| detail | TEXT | 详情 |
| ip_address | TEXT | IP 地址 |

## 6. API 接口

### 6.1 接口概览

| 模块 | 路径 | 方法 | 说明 |
|------|------|------|------|
| 服务器 | /api/servers | GET/POST/PUT/DELETE | 服务器 CRUD |
| 机柜 | /api/cabinets | GET/POST/PUT/DELETE | 机柜管理 |
| 环境 | /api/environments | GET/POST/PUT/DELETE | 环境管理 |
| 标签 | /api/tags | GET/POST/PUT/DELETE | 标签管理 |
| 用户 | /api/users | GET/POST/PUT/DELETE | 用户管理 |
| 变更日志 | /api/change-logs | GET | 变更查询 |
| 审计日志 | /api/audit-logs | GET | 审计查询 |
| 成本统计 | /api/cost | GET | 成本数据 |
| 系统设置 | /api/settings | GET/PUT | 设置管理 |
| 数据导入 | /api/import | POST | Excel 导入 |
| 版本 | /api/versions | GET/POST | 版本管理 |

**详细接口文档见**: `docs/API文档.md`

## 7. 部署架构

### 7.1 开发环境
```bash
npm run dev:all  # 同时启动前端(5173) + 后端(3213)
```

### 7.2 生产环境
```bash
# Docker 部署
cd deploy/docker
docker-compose up -d

# 或离线部署
./build-offline.sh
./deploy-offline.sh
```

### 7.3 端口说明

| 端口 | 服务 | 说明 |
|------|------|------|
| 5173 | Vite | 前端开发服务器 |
| 3213 | Express | 后端 API 服务 |
