## 1. 产品概述

### 1.1 产品简介

CMDB（Configuration Management Database）平台是一款面向研发团队的服务器配置管理工具，提供服务器资产全生命周期管理、机柜可视化配置、环境规划、操作审计等核心功能。

### 1.2 技术架构

| 层级 | 技术栈 |
|------|--------|
| 前端 | React 18 + TypeScript + Vite + Tailwind CSS |
| 后端 | Express 4 + TypeScript + better-sqlite3 |
| 数据库 | SQLite |

### 1.3 系统入口

- 前端地址：`http://localhost:5173`
- 后端地址：`http://localhost:3213`

### 2.2 模块说明

#### 2.2.1 仪表盘（Dashboard）

展示系统核心数据统计：

- 服务器总数及状态分布
- 环境分布饼图
- 角色类型分布
- 快捷操作入口

#### 2.2.2 服务器管理（Servers）

核心资产管理功能：

- 支持按 IP、主机名、状态、环境等条件筛选
- 支持自定义列表显示字段
- 支持批量导入导出 Excel
- 支持标签分类管理
- 支持变更记录查看

#### 2.2.3 服务器详情（ServerDetail）

单个服务器的完整信息：

- **基础信息**：IP、主机名、SN、CPU、内存、硬盘、厂商、型号
- **U位信息**：机柜、起始U位、占用U位
- **环境配置**：所属环境、角色类型
- **成本信息**：采购价格、采购日期、4年折旧计算
- **变更历史**：状态变更记录

#### 2.2.4 机柜管理（Cabinets）

机柜可视化配置：

- 机柜列表展示
- 可视化 U 位图（42U 标准机柜）
- 支持拖拽分配服务器U位
- 支持同步服务器数据

#### 2.2.5 环境管理（Environments）

环境规划与配置：

- 环境列表（生产、测试、开发等）
- 自定义字段管理
- 支持环境级别的字段扩展

#### 2.2.6 成本管理（Cost）

成本统计分析：

- 设备采购成本汇总
- 机柜年费统计
- 月度折旧计算
- 总持有成本统计

#### 2.2.7 审计日志（Audit）

操作审计追踪：

- 记录所有创建、修改、删除操作
- 支持按操作类型、用户、时间筛选
- 记录操作前后的数据变化

#### 2.2.8 版本管理（Versions）

数据快照与回退：

- 创建数据快照
- 查看历史版本列表
- 一键回退到指定版本

#### 2.2.9 配置管理（Config）

系统配置功能：

- **字段管理**：管理列表显示的列
- **角色类型**：定义服务器角色分类（基础服务、中间件、存储等）

## 4. 操作手册

### 4.1 服务器管理

#### 新增服务器

1. 进入「服务器管理」页面
2. 点击右上角「新增服务器」
3. 填写服务器信息（IP、主机名、配置等）
4. 选择机柜和U位
5. 选择环境、角色类型
6. 点击「保存」

#### 批量导入

1. 点击「导入」按钮
2. 下载 Excel 模板
3. 按模板格式填写数据
4. 上传填写好的 Excel 文件
5. 确认导入预览
6. 点击「确认导入」

#### 自定义列配置

1. 点击右上角「字段配置」
2. 选择需要显示的字段
3. 拖拽调整列顺序
4. 点击「保存」

### 4.2 机柜管理

#### 分配服务器U位

1. 进入「机柜管理」页面
2. 选择目标机柜
3. 点击空闲U位
4. 选择要放置的服务器
5. 确认分配

### 4.3 成本管理

#### 填写采购信息

1. 进入服务器详情页
2. 切换到「成本信息」标签
3. 填写采购价格和采购日期
4. 系统自动计算折旧

### 4.4 数据回退

1. 进入「版本管理」页面
2. 选择要回退的版本
3. 点击「回退此版本」
4. 确认操作

## 附录

### A. 数据库表结构

| 表名 | 说明 |
|------|------|
| users | 用户表 |
| servers | 服务器表 |
| cabinets | 机柜表 |
| environments | 环境表 |
| tags | 标签表 |
| server_tags | 服务器-标签关联表 |
| audit_logs | 审计日志表 |
| versions | 版本快照表 |

### B. 状态值说明

| 状态 | 说明 |
|------|------|
| 已上架 | 服务器已投入使用 |
| 维护中 | 服务器正在维护 |
| 异动中 | 服务器状态变更中 |
| 已下架 | 服务器已停用 |

### C. 折旧计算规则

- 折旧期限：4年（48个月）
- 月折旧 = 采购价格 ÷ 48
- 年折旧 = 月折旧 × 12
